# Purplee

Purplee is a Flutter weather application inspired by a modern weather UI concept from Figma. The app is designed to provide a clean, premium, and mobile-friendly weather experience with an atmospheric color palette, soft glassmorphism-inspired cards, and focused forecast information.

## Design Inspiration

This project follows the weather app UI design available in Figma:

- [Weather App UI Design](https://www.figma.com/community/file/1100826294536456295/weather-app-ui-design)

The design focuses on:

- A rich hero section for the current weather
- Daily and hourly forecast views
- Elegant card layouts for details such as humidity, wind, sunrise, and sunset
- A modern purple-toned aesthetic with a polished mobile layout

## Features

- Current weather summary with temperature and condition
- Hourly forecast cards
- Multi-day weather forecast
- Weather details such as humidity, UV index, wind speed, and pressure
- Modern UI optimized for mobile devices
- Flutter-based implementation ready for extension with live API data

## Tech Stack

- Flutter
- Dart
- Material Design

## Project Structure

## Getting Started

1. Install Flutter and ensure your environment is configured.
2. Clone this repository.
3. Run:

```bash
flutter pub get
flutter run
```

## Development Notes

This project is a UI-first weather app starter inspired by the referenced design. You can extend it by integrating a weather API such as OpenWeatherMap, WeatherAPI, or a custom backend to fetch live weather data.
